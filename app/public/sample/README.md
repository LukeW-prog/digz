# Sample photos

Development fixtures only. These back the sample listings in
`src/lib/sample-data.ts`, which are used when Supabase is not configured so
the site can be run and reviewed before any real listing exists. Every page
that falls back to sample data shows a banner saying so.

They are never shown alongside real listings, and a real listing's photos
always come from Supabase Storage instead.

## Where they came from

Unsplash. The Unsplash Licence grants free use, including commercially, with
no permission or attribution required.

They were picked to look like ordinary rooms in ordinary family homes. The
obvious stock photography — staged luxury interiors, empty furniture product
shots, estate agents holding model houses — was rejected on purpose. A digs
site that looks like a property portal reads as a scam, and designing against
glossy fixtures would have hidden that.
